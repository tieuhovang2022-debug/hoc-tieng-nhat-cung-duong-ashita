# Học Tiếng Nhật Cùng Dương Giàn Giáo

Web luyện thi JLPT N5–N2 của Dương Giàn Giáo: từ vựng, ngữ pháp (bài giảng), đọc hiểu và luyện nói theo giáo trình Minna no Nihongo (N5/N4) và Mimi kara Oboeru (N3/N2).

- 9.409 câu trắc nghiệm: Từ vựng 4.729 câu (chia phần tối đa 20 câu, 15 phút), Luyện nói 3.900 câu (50 câu/bài), Đọc hiểu 780 câu (10 câu/bài)
- 78 bài giảng ngữ pháp: 260 mẫu câu, 521 ví dụ Nhật – Việt

## Cách dùng

Tải toàn bộ repo này về (nút **Code → Download ZIP**), giải nén, rồi mở file `index.html` trong trình duyệt là dùng được ngay — không cần cài đặt, không cần mạng.

Các file `data-*.js`, `app.js`, `img-*.js` là dữ liệu và mã chạy của web, phải để **cùng thư mục** với `index.html`.
