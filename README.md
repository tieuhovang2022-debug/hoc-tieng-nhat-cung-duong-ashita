# Học Tiếng Nhật Cùng Dương Ashita

Web luyện thi JLPT N5–N2 của Dương Ashita: từ vựng, ngữ pháp (bài giảng), đọc hiểu và luyện nói theo giáo trình Minna no Nihongo (N5/N4) và Mimi kara Oboeru (N3/N2).

- 9.409 câu trắc nghiệm: Từ vựng 4.729 câu (chia phần tối đa 20 câu, 15 phút), Luyện nói 3.900 câu (50 câu/bài), Đọc hiểu 780 câu (10 câu/bài)
- 78 bài giảng ngữ pháp: 260 mẫu câu, 521 ví dụ Nhật – Việt
- Mở file `index.html` trong trình duyệt là dùng được ngay (không cần cài đặt, không cần mạng)
